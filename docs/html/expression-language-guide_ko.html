신청의 표현 언어

Expression Language는 NiFi 애플리케이션을 통해 크게 사용됩니다. 제품 정보 모든 프로세서 속성은 Expression Language를 지원하지 않지만. 또는 아니 A Property는 Expression Language가 프로세서 개발자에 의해 결정됩니다. 프로세서가 작성되었습니다. 그러나, 응용 프로그램은 명확하게 각 속성에 대해 설명합니다. Expression Language가 지원되는지 여부.
